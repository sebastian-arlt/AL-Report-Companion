# Microsoft RDL validation schemas

These schemas are bundled unchanged from Microsoft's public schema endpoints:

- https://schemas.microsoft.com/sqlserver/reporting/2005/01/reportdefinition/ReportDefinition.xsd
- https://schemas.microsoft.com/sqlserver/reporting/2008/01/reportdefinition/ReportDefinition.xsd
- https://schemas.microsoft.com/sqlserver/reporting/2010/01/reportdefinition/ReportDefinition.xsd

Retrieved 2026-10-06. Copyright and notices inside each file belong to Microsoft;
the extension's MIT license does not replace those notices.

Validation is local and requires no network access. XML DTDs and external
resolution are disabled. Schema validation checks XML structure and values;
it does not compile expressions or prove that a particular NAV runtime can
execute the report.
